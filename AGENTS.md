# Shared AI agent instructions

For knowledge-map or knowledge-gap tasks, read and follow [`skills/knowledge-completion/SKILL.md`](skills/knowledge-completion/SKILL.md). This is the vendor-neutral workflow source for Codex, Claude Code, Cursor, and other repository agents.

The executable implementation is `npm run agent`. Do not replace the deterministic compiler with an unbounded prompt. Keep note-backed evidence, model proposals, and external evidence distinguishable; unsupported adjacent concepts remain boundary candidates.
